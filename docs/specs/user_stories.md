# User Stories

| ID | Story |
| --- | --- |
| NR-US-001 | As an engineer, I want to run an objective with `--pack coding` so that the system uses the right agents and policies. |
| NR-US-002 | As an operator, I want tools with `risk: high` to require approval so that I do not lose work to a runaway agent. |
| NR-US-003 | As a power user, I want to describe a workflow pack in a markdown template so that I do not need to learn the YAML DSL. |
| NR-US-004 | As an SRE, I want every run to produce a JSONL trace with secrets redacted so that I can audit incidents. |
| NR-US-005 | As a researcher, I want deterministic mock mode so that I can compare runs and replay golden fixtures. |
| NR-US-006 | As a marketer, I want to use Neuronium to plan a campaign with the marketing pack so that I do not need to reinvent the workflow. |
| NR-US-007 | As a recruiter, I want to screen candidates with the HR pack so that I get a shortlist + rationale without manual scoring. |
| NR-US-008 | As an integrator, I want the API/CLI to be stable so that I can build on top of it. |
